# 물때 3

거짓말을 알아보는 능력을 가진 주인공이 경찰 자문으로 사건을 해결하는 추리 게임. 물때 시리즈 3편.

## 플레이

- 웹: GitHub Pages 주소(저장소 Settings → Pages)에서 크롬으로 바로 플레이
- 로컬: 저장소를 받아 `index.html`을 크롬으로 열기 (설치·빌드 필요 없음)

## 구성

| 막 | 사건 | 거짓 판별 |
|---|---|---|
| 1막 | 경찰서 앞, 김준서에게 능력 증명 (튜토리얼) | 3회 |
| 2막 | 강도·폭행 | 3회 |
| 3막 | 현직 경찰의 계획살인 (결론이 강제되는 막) | 3회, 전부 진실 |
| 4막 | 불탄 전세방 | 사용 불가 |
| 5막 | 자수한 청년 | 2회 |
| 6막 | 고치는 사람들 | 무제한 |

엔딩은 진엔딩(특별형사 임명)과 배드엔딩(3막 외 심문 실패) 두 개.

## 규칙

- 심문 전 물건 3개 선택. 물건이 없으면 필요한 질문이 보이지 않아 돌려 물어야 함(질문 +1)
- 질문·반박 1회 = 5분, 제한 35분 (질문 4 + 반박 3, 실수 허용 없음)
- 함정 질문을 고르면 필요한 질문 +1
- 거짓 판별은 노트에서 문장 하나씩, 시간 소모 없음
- 1~4막은 진실 문장 반박이 항상 틀림. 5막부터는 진실로 판별된 문장도 증거로 반박 가능
- 심문 중 저장 불가. 실패하면 물건 고르기부터 다시
- 3막은 시간이 끝나면 어떤 키를 누르든 "그는 죄가 없습니다."가 입력됨

## 파일

- `index.html` 화면 뼈대
- `style.css` 디자인
- `js/scenario.js` 대사·사건 데이터 (대사 수정은 여기서)
- `js/engine.js` 게임 진행 규칙
